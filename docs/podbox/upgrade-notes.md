- **Logging**'s **Last.fm Logger** is now **On + Last.fm**: it keeps the
  iPod's own listening log as well as the scrobble log, so an uploader that
  empties the scrobble log no longer empties the Playback Report and Spun
  with it. Plays the uploader has already cleared cannot be brought back.
- **Artist Bio & Liner Notes** is now **Liner Notes**, with two more pages, Track
  and Credits, and a switch for each page. Its **Background** choice **Theme** is
  now called **Plain**; your setting is kept.
